PERSONAL HEALTH ASSISTANT CHATBOT

A web-based AI chatbot that offers basic health guidance based on user-provided symptoms. It leverages the DeepSeek-V3-Base model via the OpenRouter API to generate intelligent and context-aware responses. Built using Flask, this project features a responsive user interface and real-time interaction, making it ideal for initial health insights. 
(Note: This tool is not a replacement for professional medical advice.)
